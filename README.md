# Portfolio
1. Put your photo at `assets/portrait.png` (transparent PNG cut-out of face/shoulders looks best; a plain light background also works).
2. In VS Code install the **Live Server** extension, right-click `index.html` -> *Open with Live Server*.
   (A local server is required — opening the file by double-click blocks the image/module loading.)
3. Edit text in `index.html`, colours in `style.css` (`:root`), particles in `script.js` (`COUNT`, `PORTRAIT`).
